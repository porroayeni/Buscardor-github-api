#Buscador de Repositorio GitHub API
Aplicación web interactiva desarrollada para consultar repositorios mediante la API REST de GitHub.
## Funcionalidades
- Búsqueda de repositorios por usuario.
- Filtro de ordenamineto por fecha de actualizacion, creacion o nombre.
- Resumen estadistico de los lenguajes mas utilizados.
- Paginación dinámica mediante botón "Cargar mas".
- Control de limite de peticiones restantes (´x-ratelimit-remaining`).

## Pregunta de Seguridad 
**¿Por que nunca se debe incluir un token de acceso en un repositorio publico?**
Los repositorios publicos son rastreados por bots automatizados. Incluir un token expondria tu cuenta a modificaciones no autorizadas, borrado de proyectos suplantacion de identidad
